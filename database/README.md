# Shobi database

All catalog data, source evidence, visual assets and audit material live under this directory.

| Folder | Contents |
| --- | --- |
| `catalog/` | Current full catalog, final 2,253-unique-perfume catalog, site projection and scope certification. |
| `source/` | Live Shobi export and Shobi-to-Fragrantica identity mappings. |
| `assets/perfumes/` | Perfume-bottle images and the code-to-image map. |
| `assets/note-icons/` | Note icons and the note-to-icon map. |
| `fragrantica/` | Fragrantica source archive, including Social Card images, manifests and extracted records. |
| `archive/` | Historical catalog snapshots and prior source material. |
| `reviews/` | Manual Social Card review sheets and review manifests. |
| `audits/` | Validation proofs, recovery reports and historical audit outputs. |

The site loads `catalog/catalog_final_perfume_only.json`; the full final database is `catalog/database_final_perfume_only.json`.
